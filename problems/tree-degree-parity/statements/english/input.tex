The first line contains one integer $n$ ($1 \le n \le 200000$).

The second line contains a binary string $s$ of length $n$.

Each of the following $n-1$ lines contains two integers $u$ and $v$
($1 \le u,v \le n$, $u \ne v$), meaning that the tree has an edge between
vertices $u$ and $v$. The given graph is guaranteed to be a tree.
