If the graph contains no cycle, print $\texttt{FOREST}$.

Otherwise, print $\texttt{CYCLE}$ followed by an integer $k$ and then $k$ distinct vertex labels $v_1,v_2,\ldots,v_k$ ($3 \le k \le n$). The graph must contain every edge $v_i v_{i+1}$ for $1 \le i < k$ and the edge $v_kv_1$. The vertices are listed in their order around the cycle. Any valid cycle may be printed.
