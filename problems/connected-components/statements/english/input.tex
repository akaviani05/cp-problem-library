The first line contains two integers $n$ and $m$ ($1 \le n \le 200\,000$, $0 \le m \le \min(200\,000,\frac{n(n-1)}2)$), the number of vertices and edges.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u,v \le n$, $u \ne v$), describing an undirected edge. No pair of vertices is connected by more than one edge.
