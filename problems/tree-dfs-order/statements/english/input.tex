The first line contains two integers $n$ and $r$ ($1 \le n \le 200\,000$, $1 \le r \le n$), the number of vertices and the starting vertex.

Each of the next $n-1$ lines contains two integers $u$ and $v$ ($1 \le u,v \le n$, $u \ne v$), describing an edge of the tree. The input edges are distinct, and the graph they describe is connected.
