# Contract and correctness

The task is one batch query: read two signed integers a and b and print a-b.
Because no bounds were specified, choose -10^18 <= a,b <= 10^18. The input is
one line, one space between the operands, and a final newline. There is no test
count. The answer uses canonical decimal notation, as required by the plain
token checker. Limits are 1 second and 64 MiB.

The main solution evaluates precisely the required expression. Its result
lies in [-2*10^18, 2*10^18], within signed 64-bit range, so subtraction cannot
overflow. It uses O(1) time and O(1) auxiliary space.

The independent C++ reference parses signed decimal strings, negates the sign
of b, and combines the magnitudes using digit addition or subtraction. Adding
digits propagates a carry; subtracting from the larger magnitude propagates a
borrow. Both operations are ordinary positional decimal arithmetic. The sign
is that of the common-sign operands or the larger magnitude, with zero
normalized to 0. It does not use native wide-integer subtraction. The Python
oracle instead relies on arbitrary-precision integer subtraction, independent
of both C++ width and the digit implementation. The three manual answers were
also calculated directly: 7-2=5, 2-7=-5, and -4-(-9)=5.

Packaged coverage comprises 3 manual samples and 24 generated tests:

- boundary: all 9 ordered pairs from {-10^18, 0, 10^18}, including both extreme
  results and equal boundary operands;
- fixed: 4 near-boundary pairs, testing opposite signs and differences of 1;
- random: 4 full-range and 4 small-range pairs from deterministic Testlib seeds;
- equal: 3 seeded full-range pairs whose answer must be zero.

The stress generator exhausts all 441 ordered pairs from [-10,10] and adds
decimal carry/borrow cases around powers of ten up to 10^18. The validator
checks both numeric bounds, exactly two operands, a single-space separator,
one terminating line break, and EOF. Its fixtures include all four bound
violations and malformed spacing, token counts, numbers, and line endings.
Checker fixtures cover positive, negative, and zero answers, harmless output
whitespace, wrong values/signs, missing/extra output, and noncanonical numerals.

The tagged wrong solution returns |a-b|, confusing signed difference with
distance. Sample 2 (2 7) rejects it: expected -5, actual 5. Large negative
differences also reject it. Signed 32-bit arithmetic is insufficient for the
chosen bounds; the boundary tests expose that separate common error.

Verification evidence is generated by cppl verify and cppl inspect; this
review records the design, not an invented execution result.
